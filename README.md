# The Return of Skambor — RPG em Console

Jogo de RPG desenvolvido em C# para console, criado durante o aprendizado de Programação Orientada a Objetos (POO). O projeto foi usado como forma de praticar os pilares de POO (encapsulamento, herança, polimorfismo e abstração) em um contexto prático.

## Tecnologias

- **Linguagem:** C#

## Funcionalidades

- Narrativa linear
- Sistema de batalha
- Sistema de ganho de experiência (XP) e evolução do personagem
- Gerenciamento de personagem, armas e atributos

## Estrutura do projeto

- `Personagem.cs` — lógica do personagem jogável
- `Prota.cs` — protagonista e suas características
- `Arma.cs` — sistema de armas
- `Contas.cs` — cálculos e regras do jogo (dano, XP, etc.)
- `Program.cs` — ponto de entrada e loop principal do jogo

## Como executar

1. Abra o arquivo `.sln` no Visual Studio.
2. Compile e execute o projeto (F5).
3. O jogo roda diretamente no console.

## Aprendizados

Projeto voltado para consolidar os fundamentos de POO em C#, aplicando os conceitos em um sistema com regras de jogo, estado de personagem e progressão.

## Time

Projeto desenvolvido em grupo, como parte do aprendizado de Programação Orientada a Objetos no curso técnico.
